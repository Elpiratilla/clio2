Riesgos del uso excesivo de redes

El uso excesivo de las redes sociales puede afectar tu salud mental, emocional y tu rendimiento diario. Informarte es el primer paso para utilizarlas de manera responsable.

Infórmate es el primer paso para tomar el control.

Reconocer los riesgos te ayuda a tomar mejores decisiones en el uso diario de las redes sociales.

Aviso importante: El contenido de este sitio web es puramente educativo e informativo y no sustituye la consulta, el diagnóstico o el tratamiento médico profesional.
